# hardware — 機体

## サーボ選定の必須条件

機械学習をやる上での前提条件。**ここは妥協しないこと。**

- 現在角度が読める
- 現在電流（またはトルク）が読める
- 50Hz 以上で読み書きできる

ログが取れない機体では、学習も原因分析もできない。

## 設計方針

- **関節数を欲張らない。** 下半身12自由度で十分。増やすほど学習も実装も難しくなる
- **IMU は必須。** RL の観測に胴体の角速度・姿勢が要る
- **脚は軽く。** 脚の慣性が大きいと sim と実機のずれが致命的になる
- **バックラッシュの小さいサーボを選ぶ。** sim-to-real 失敗の主要因の一つ
