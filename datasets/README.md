## 記録すべきこと

ログを取ったら、**そのときの条件を必ず一緒に残す。**
条件が分からないログは、後から見ると価値がゼロになる。

- コミットハッシュ（`git rev-parse HEAD`）
- 使った制御器・ポリシー
- 機体の状態（バッテリ電圧、キャリブレーションの日付）
- 路面の条件
