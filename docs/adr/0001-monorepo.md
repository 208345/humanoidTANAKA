# ADR-0001: 単一リポジトリ（モノレポ）で管理する

- **日付**: 2026-08-09
- **状態**: 採用

## 背景

firmware / 上位制御 / シミュレーション / 学習を3人で並行開発する。
リポジトリを分けるか、1つにまとめるか。

## 決定

1つのリポジトリにまとめる。

## 理由

通信仕様を1つ変えると firmware と control が同時に変わる。
リポジトリが分かれていると「どのコミットの組み合わせなら動くのか」が
誰にも分からなくなり、3人規模でも短期間で破綻する。

モノレポなら1つのコミットが常に「動く組み合わせ」を表す。

## 結果として起きること

- リポジトリのサイズが増えやすい → 大きいバイナリは Git に入れない運用で対処する
- CI が全体を対象にするため実行時間が伸びる → 必要になったら差分実行を導入する
