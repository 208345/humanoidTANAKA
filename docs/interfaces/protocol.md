## 送信パケット（PC → マイコン）: 関節指令

| オフセット | 型 | 内容 |
|---|---|---|
| 0 | uint16 | ヘッダ `0xA5A5` |
| 2 | uint8 | コマンド種別（0=脱力, 1=位置指令） |
| 3 | uint8 | シーケンス番号（受信側で欠落検出に使う） |
| 4 | int16 × 12 | 関節角 [rad] × 1000（`joints.md` の ID 順） |
| 28 | uint16 | CRC16 |

## 受信パケット（マイコン → PC）: 状態

| オフセット | 型 | 内容 |
|---|---|---|
| 0 | uint16 | ヘッダ `0x5A5A` |
| 2 | uint8 | シーケンス番号（送ったものをそのまま返す＝往復遅延の計測用） |
| 3 | uint8 | ステータスフラグ（エラー、脱力状態など） |
| 4 | uint32 | マイコン側タイムスタンプ [us] |
| 8 | int16 × 12 | 関節角 [rad] × 1000 |
| 32 | int16 × 12 | 関節電流 [mA] |
| 56 | int16 × 4 | IMU クォータニオン × 10000 |
| 64 | int16 × 3 | IMU 角速度 [rad/s] × 1000 |
| 70 | uint16 | CRC16 |

## 安全機構（必ず実装する）

- **ウォッチドッグ**: 100ms 以上指令が来なければマイコン側で自動的に脱力する
- **可動域チェック**: `joints.md` の範囲外の指令はマイコン側で拒否する
- **非常停止**: 物理的なスイッチで電源を切れるようにする

> PC 側がクラッシュしたときにサーボが最後の指令を保持し続けると、
> 機体が壊れるか焼ける。**ウォッチドッグは Phase 2 の必須要件。**

## 設計メモ

- 浮動小数ではなく int16 に固定小数で載せているのは、帯域とパースの単純さのため
- シーケンス番号を返させているのは、往復遅延を実測するため。
  sim-to-real では**遅延の実測値がドメインランダム化のパラメータになる**ので、
  最初から測れるようにしておく
