## ワールド座標系

- 原点: 起動時の胴体を地面に投影した点
- X: ロボットの正面方向
- Y: ロボットの左方向
- Z: 鉛直上向き

（右手系。ROS の慣習に合わせてある。将来 ROS 2 に載せ替える場合の手間を減らすため）

## 単位

| 量 | 単位 |
|---|---|
| 長さ | m |
| 角度 | rad |
| 時間 | s |
| 質量 | kg |
| 力 | N |
| トルク | Nm |

**degree と mm は使わない。** 表示のときだけ変換する。
単位の混在は、原因が分かりにくいバグを生む最大の原因。
