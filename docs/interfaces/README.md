# インターフェース仕様

**このフォルダの内容はコードより先に決める。** ここが3人の作業をつなぐ唯一の接点。

変更するときは Issue を立てて全員で合意すること。1人で変えると他の2人の作業が壊れる。

| ファイル | 内容 |
|---|---|
| `joints.md` | 関節の番号・名前・回転方向の符号・可動域・原点姿勢 |
| `frames.md` | 座標系の定義（原点・軸の向き） |
| `protocol.md` | PC ⇄ マイコン間の通信フォーマット |
