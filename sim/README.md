# sim — シミュレーション

**実機は1台しかない。sim が無いと3人のうち2人が常に待ちになる。**
ここへの投資が、チーム開発では最も効果が大きい。

## scenarios/

再現性のあるテストシナリオを置く。

- `stand.py` — 直立を保てるか
- `one_leg.py` — 片足立ち（Phase 3）
- `push.py` — 外乱を加えて復帰できるか
- `walk_straight.py` — 直進歩行（Phase 4）

シナリオはスクリプトとして実行でき、**成否を自動判定できる**ようにする。
目視確認だけに頼ると、変更で壊れたことに気づけない。
