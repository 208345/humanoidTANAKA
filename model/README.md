# model — 寸法・質量の唯一の正

| ファイル | 用途 |
|---|---|
| `params.yaml` | 数値の正。人間もコードもここを読む |
| `humanoid.xml` | MuJoCo 用モデル（MJCF）※ Phase 0 で作成 |
| `humanoid.urdf` | 汎用のロボット記述。可視化や他ツール連携用 ※ Phase 0 で作成 |

## 原則

**同じ数値を2箇所に書かない。** `humanoid.xml` は `params.yaml` から
生成するのが理想（`scripts/build_model.py` を用意する）。

手で両方を編集すると、いつか必ずずれる。ずれた瞬間に
「sim では歩くのに実機では歩かない」の原因が特定不能になる。

## Phase 0 の作業

1. CAD から各リンクの質量・重心・慣性テンソルを出す
2. `params.yaml` の `null` を全部埋める
3. MJCF を作り、MuJoCo で表示して見た目が実機と一致することを確認する
4. `meta.status` を `fixed` に変える

## 慣性テンソルについて

面倒でも CAD から実際の値を出すこと。
「だいたい直方体」で近似すると、歩行のような動的な運動では sim と実機が一致しない。
ここの手抜きは Phase 5 で必ず跳ね返ってくる。
