# firmware — マイコン側

サーボ制御ループ（1kHz）と、PC との通信を担当する。

通信フォーマットは `docs/interfaces/protocol.md` が正。
**実装と文書がずれたら、必ず文書を先に直す。**

## 必須の安全機構

- **ウォッチドッグ** — 100ms 指令が来なければ自動的に脱力する
- **可動域チェック** — `docs/interfaces/joints.md` の範囲外の指令を拒否する
- **非常停止** — 物理スイッチで電源を落とせるようにする

PC 側がクラッシュしたとき、サーボが最後の指令を保持し続けると機体が壊れる。
ウォッチドッグは Phase 2 の必須要件であり、後回しにしないこと。

## 環境

PlatformIO を推奨（VS Code の拡張機能から使える）。
Arduino IDE でも動くが、複数人でのバージョン管理には向かない。
